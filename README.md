# PROJETO-PLATAFORMA-INTELIGENTE-DE-DIAGN-STICO-T-CNICO-CRC
Crie um app web de diagnóstico técnico com IA para falhas em componentes Scania. Cadastre veículo, componente, fotos, histórico, telemetria, matriz de carga e velocidade, topografia e relato do condutor. Cruze evidências, sugira causas, guie a investigação e gere relatório técnico para validação humana.
